# dsh-check

两条自查工具，给「交付前过机器校验」用：

| 工具 | 查什么 |
| --- | --- |
| `net-clean-check` | 净版交付物里的「过程痕迹」：实测／对照／已验证／已删／试过／扫描／配对…，以及因为／由于／所以这类论证连词；按「文件: 行号 ＋ 词」列出 |
| `profile-lint` | `$DSH_HOME` 下画像文件的排版与错层：加粗、引用块、行首缩进（画像用纯文本框编辑、不渲染 markdown）、规则口吻混入、跨层重复条目、体积超限 |
| `gate-check` | 关卡勾稽：模板每节要求正文非空白字符 ≥10 且有一行 `EVID:` 指针（文件:行 必须真实存在／`tool:名字{...}`／`cmd:...`／`SKIP:理由`），跑完即删模板、只留日志 |

## 为什么要机器查

净版交付物只该写「做什么」和「最终结论」，过程痕迹是项目说明，混进成品会让人读到推演而不是结果。画像写在纯文本框里，加粗和缩进在编辑器里是字面噪音；同一条内容在通用画像与任务画像里各写一份，改一处必漏一处。这两类问题靠自觉拦不住。

## 工具

### `net-clean-check`

```
参数：files（字符串数组，必填）——要校验的文件
输出：ok / exitCode / text；命中按文件列出 [A] 或 [B]、行号、命中词与整行摘要
```

反引号里的内容不参与匹配（命令与文件名属于引用）。A 组必删或搬去项目说明，B 组连词通常也该删。

### `profile-lint`

```
参数：无
输出：ok / exitCode / text；逐文件给「格式合格」或问题清单，附规则口吻、超长条提示
```

检查项：首行标题、加粗、引用块、行首缩进、体积上限 64KB、跨层重复条目；提示项（不影响退出码）：体积超过 8000 字节、规则口吻与机制条文、单条超过 110 字。

### `gate-check`

```
参数：file（模板路径）｜init（生成空白模板）｜clean（删本会话模板与日志）｜keep（不删模板）｜session
输出：ok / exitCode / text；逐节给字数、EVID 判读与 ✓/✗，末尾给「关卡：N/16」
```

模板在 `$DSH_HOME/gate/<会话id>.md`。默认不论过没过，跑完即删模板，只写一行日志到 `.log`——防止下一轮复用旧证据。`SKIP` 要写 ≥10 字的具体理由，16 节全 SKIP 判未做。

## 安装

```sh
dsh plugin --profile desktop add dsh-check
```

装完重启 DSH。要求 DSH >= 0.2.1-alpha.1。
