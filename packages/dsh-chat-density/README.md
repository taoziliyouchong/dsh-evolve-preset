# dsh-chat-density

把聊天区里「对齐栏」与「收尾检测」两块的字号、行距、颜色统一调小变淡，正文保持原样。

进化模式每轮回复开头是四行对齐栏、结尾是收尾检测。两块都是引用块，默认字号和正文一样，屏幕上一眼望去全是加粗的小标题。这个插件只调这两块：12.5px、次要色、左侧细线，正文、代码块、输入框都不动。

## 怎么认这两块

不看类名，看块内文本——打包后的类名会变，文本不会：

- 对齐栏：块首是「本层目标：」或「根本目标：」，也兜旧写法的「我按哪个目标改：」「服务上层：」；
- 收尾检测：块内含「收尾检测」「本轮五项」「待确认：」等。

命中就给块打 `data-zz="quiet"`，样式由同一套选择器生效。只挑 `blockquote`，排除代码块里的引用。

## 行为

- 补标不摘标：另一个实例或重渲染把标记拿掉时，下一帧补回来，不会出现“一会儿对、一会儿又变回去”。
- DOM 变更（流式追加、重渲染）随时补标；800ms 轮询兜底。
- 同一页面加载两次时，新实例先停掉旧实例的扫描器。

## 安装

```sh
dsh plugin --profile desktop add dsh-chat-density
```

装完重启 DSH。要求 DSH >= 0.2.1-alpha.1。

## 结构

- `src/entry.jsx` —— 浏览器半边源码（判定、补标、样式）
- `lib/client.js` —— 构建产物，提交进仓库（从 GitHub/npm 安装时不跑构建）
- `index.js` —— 宿主半边空壳
